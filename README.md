#  TalentMind AI — Intelligent Workforce Intelligence Platform

TalentMind AI is an intelligent workforce intelligence platform that combines Machine Learning, Generative AI, Predictive Analytics, Explainable AI, and Multi-Agent Reasoning to transform workforce data into meaningful insights and actionable recommendations.

Instead of functioning as a traditional HR dashboard, TalentMind AI creates an intelligent decision-support layer for modern HR teams.

Core Intelligence Pipeline:

Workforce Data → AI Analysis → Prediction → Explanation → Recommendation → Action

## 🚀 Key Features

###  AI HR Command Center

A centralized workforce intelligence dashboard providing insights into:

- Workforce overview
- Department distribution
- Employee analytics
- Workforce trends
- Skill intelligence
- Attrition indicators
- Workforce risks
- AI-generated insights
- Recommended actions

###  AI Recruitment Intelligence

Analyze candidates against job requirements using AI-powered recruitment intelligence.

Features include:

- Resume-to-job-description matching
- Candidate relevance analysis
- Skill matching
- Missing skill detection
- Explainable candidate analysis

###  Skill Gap Analyzer

Identify missing skills and generate personalized employee development recommendations.

Features include:

- Current skill analysis
- Required skill identification
- Skill gap detection
- Learning recommendations

Create an AI-powered Skill DNA profile for employees.

The profile can represent:

Visualize relationships between employees, skills, roles, and departments.

This helps HR teams understand how capabilities are distributed throughout the workforce.

###  Attrition Prediction & Explainable AI

TalentMind AI analyzes workforce attributes to identify potential employee attrition risks.

Instead of providing only a prediction, the system adds an explanation layer to help users understand contributing factors.

The Risk Radar provides an AI-powered view of potential workforce risks, including:

- Attrition risk

- Talent gaps

###  AI Action Center

TalentMind AI converts workforce insights into actionable recommendations.

Potential actions include:

- Employee development
- Skill training
- Retention initiatives
- Recruitment recommendations
- Workforce planning

###  Multi-Agent HR Orchestrator

TalentMind AI includes a multi-agent reasoning architecture where specialized AI agents can support different HR intelligence workflows.

Agents can support:

##  Local Installation

### 1. Clone the Repository

git clone https://github.com/rohanbhowm25308/TalentMind-AI.git

cd TalentMind-AI

### 2. Create a Virtual Environment

python -m venv venv

### Windows

venv\Scripts\activate

### macOS / Linux

source venv/bin/activate

### 3. Install Dependencies

pip install -r backend/requirements.txt

### 4. Configure Environment Variables

Create a .env file inside the backend directory.

GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=your_preferred_groq_model

### 5. Start the Application

cd backend

python app.py

Then open the application in your browser.

##  Responsible AI

TalentMind AI is designed as a decision-support system, not as an autonomous replacement for HR professionals.

AI-generated insights should be reviewed by qualified human decision-makers before being used for consequential employment decisions.

The platform emphasizes:

- Explainability
- Evidence-based insights
- Human oversight
- Responsible AI usage
- Data privacy
- Transparent recommendations

Predictions and recommendations should be treated as analytical signals rather than automatic decisions.
